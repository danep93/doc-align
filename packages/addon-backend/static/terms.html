What the Add-on does

doc-align lets a document owner snapshot a Google Docs revision and request sign-off from named signers. Signers commit to that specific revision; if the document changes afterward, signers are notified and asked to re-review. The Add-on tracks sign-off status — it does not enforce or block editing, and it does not render its own diffs (it links to Google's native version history).
